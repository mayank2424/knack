Give your agent a knack.

Six skills for developers and designers. Each one ships scripts that render, measure and check its own work, so your agent can see the result before you do.

❯/plugin marketplace add mayank2424/knack
❯/plugin install knack@knack
$npx skills add mayank2424/knack

Works with Claude Code, Codex, Cursor, Gemini CLI, OpenCode and 40+ more. Add --skill motion-video to pick one.

$git clone https://github.com/mayank2424/knack
$cp -r knack/skills/* ~/.claude/skills/
01

Verifies, not just advises

Most skills are prose. Knack skills bundle deterministic tooling (Playwright, axe-core, ffmpeg, pixel diffs), so the agent looks at real evidence and iterates.

02

Works in your agent

Plain SKILL.md files in the open Agent Skills format. Install as a Claude Code plugin, or with npx skills for any compatible agent.

03

No lock-in, no telemetry

MIT licensed, pinned dependencies, local-only scripts. Read every line, fork it, ship your own. Outputs are plain HTML, PNG, JSON and MP4.
