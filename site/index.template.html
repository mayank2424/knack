      How a Knack skill works

      A skill is a folder: a SKILL.md the agent follows, scripts it runs, and references it reads when it needs them. The scripts turn "looks done" into something the agent can check.

      1. Act

        Writes the composition, the flow file or the fix, following the skill's workflow.

      2. Measure

        Runs the bundled tool: render.mjs --check, audit.mjs, sweep.mjs, capture.mjs.

      3. Look

        Reads the evidence: filmstrip.png, annotated screenshots, report.json, compare.png.

      4. Repeat

        Fixes what the evidence shows and runs again until it's clean, then reports with the proof attached.

      Add a skill

      Knack takes skills that check their own output. If yours renders, measures or diffs something real, open a pull request and it will appear here.

      Contributing guideRequest a skill

      • A SKILL.md under 500 lines that leads with the workflow
      • Scripts with --help, pinned dependencies and clear errors
      • A small example the skill can be run against
      • A preview image made from the skill's real output
