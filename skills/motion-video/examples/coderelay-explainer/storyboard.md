# CodeRelay: review comments → one prompt (15s explainer)

**Goal:** In one viewing, a developer gets it: the comments on a pull request turn into one structured prompt for their coding agent, and that's what CodeRelay does.
**Platform:** Chrome Web Store listing video + X feed. 1920×1080, 60fps (camera moves on UI), 15s, sound on but readable muted.
**Look:** the CodeRelay site's own system. Void navy `#020617` with the hero's three soft glows and a faint relay mesh; Sora (600 display, 400 body) + JetBrains Mono for labels, both self-hosted from `site/fonts/`. The brand's colour semantics carry the story: **amber `#ffb454` = the human reviewer**, **relay blue `#4d8dff` = CodeRelay**, **cyan `#5fe3ff` = the machine/agent**. The real panel (light UI) is the only bright object, so it's always the focal point.
**Audio:** synthesized score, 120 BPM, D minor, `driving` arrangement: filtered pad only under the problem, drums and bass drop in when the panel lands, drums out for the end card. Cues on every cut and UI action.
**Source of truth:** every claim and every on-screen word comes from the repo: README tagline, `site/index.html` hero ("Your reviewer said it. Your agent never heard it." and its four example comments), the store screenshots (`store/screenshots/01–03`, cropped to the panel, untouched pixels), the panel footer copy and the real copy toast (`App.tsx`: "Prompt copied — 13 comments", styles from `styles.css`).

Beat grid: `B(n) = n × 0.5s`. Shot lengths 7 / 2 / 6 / 5 / 3 / 7 beats.
